# BF144-D97 回弹采样施力后的接触速度

fresh PA的head材质与D65a受跟踪源记录逐字节相同。源在力/重力积分与位置预测之后检测接触，并用此时两个body的线速度、角速度和接触力臂生成回弹目标；Avian原始manifold在力积分之前记录该速度。

目标在速度积分后、接触warm-start前，按当前solver的线/角速度重算Ragdoll接触点法向速度；普通接触保持原路径。已写带角速度的阶段对照，以及加载head在30/60Hz、有无重力时的回弹对照；这些测试也覆盖D91/D92/D93的前置配置。

接触几何时机归D98，多点回弹预算归D99；测试、消融及Playground待统一Gate。
