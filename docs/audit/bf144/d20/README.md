# BF144-D20 空中撞击动态物体的接触速度

fresh UE 源码显示 `p.UseTargetVelocityOnImpact` 默认开启：首次 Falling 碰撞的目标为模拟物理刚体且角色速度非近零时，沿 `ImpactNormal` 用接触点速度修正角色速度。接触点速度包括物体线速度及角速度叉乘相对位置；静态和运动学目标不走该分支。重新扫描项目与引擎配置目录未发现覆盖，记录了配置文件清单哈希。当前原生 reader 不能设置移动刚体初速，本目录的 ±1 m/s 控制值是源公式推导，不冒充原生动态碰撞样本。

目标在主 Falling 和已有物理补时共用的 sweep 中解析命中 collider 所属刚体，复用现有接触点速度计算；保留原滑动位移，仅修正源要求的首撞速度。已写动态、静态、运动学、零速、角速度、子 collider 和加载角色事务对照。历史目标报告 `target/bf144/06/moving_body/` 已缺失；测试、消融、图审计和真实 Playground Gate 待全部静态修复及 Bevy/依赖升级后执行。
