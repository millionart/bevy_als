# BF144.507 自动落地 Roll 淡出时钟

原生读取 AM_Als_Roll 的标准 0.1/0.3 秒 HermiteCubic 混入混出、精确分支通知时间及 14 条播放序列。公开 Bevy Roll 状态用同一组 F32 步长重放。30 Hz 两端分别与 .506 的已封存整角色轨迹逐值一致。源播放位置在通知点拆分、按子步累积，使用剩余片段时长开始淡出，随后累积 Alpha 和剩余时间。目标以 elapsed 反算播放位置、触发点和剩余比例。原生 F32 模型完整复现探针。分别替换分支拆分、淡出门槛、淡出时长、Alpha 历史和曲线方向，逐项留下可重复失败。

两个临界步长的目标在落地偏移 26 提前恢复底层图，源到偏移 27 才恢复。可见 Playground 将其中一个步长施加在偏移 25。偏移 26 的目标槽权重为 0.965706408，Grounded 两节点恢复更新。单帧替换为源权重 1 后，物理状态和 Roll 时钟逐值相同，Grounded 仍保持旧值，偏移 27 才恢复更新。重新运行原入口后参数报告逐字节相同。另一个临界步长在原生和目标公开状态中复现。

`verify.py` 核对原生和公开状态时钟，`finalize.py` 核对可见实跑与压缩哈希。时钟差异及其消费行为并入既有 D118。
