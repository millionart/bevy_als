# BF144.512 实际 Sprint 加速度消费

原生角色与 Bevy 可见 Playground 均以实际输入进入 Sprint。UE 在序号 25 入场，39 达到 0.5 秒。Bevy 在序号 24 入场，38 达到 0.5 秒。两端均在序号 60 退出并归零生产者状态。入场序号受各自实际物理轨迹影响，已有 D05 的站姿加速度配置差在起步重现。

各自实测输入通过同一 F32 递推精确复现。映射范围 0–0.25 在插值前允许外推，之后才截断实际混合权重。提前截断的对照发生失配。UE 和 Bevy 的加速动画权重首次低于 1 的序号分别为 41 和 43。

目标入场时只把前向加速度读数改成 0.125，混合权重由 1 变为 0.5，两条 Sprint 播放器求值，最终 Root 有 72 个骨骼记录改变。目标在 0.5 秒时收到 0.9 的单帧控制，生产者仍写零。初版截止观察要求重复运行中的末位值完全相同，触发了诊断断言。最终记录实际注入值并核验时间和输出。独立无控制恢复运行在第 24 序号逐值相同，从第 34 序号起出现物理末位变化。第 38 序号的时间、输入权重和有效权重精确相同。
