# BF144-D256a2 动画速度的源单位舍入

fresh ALS 源码显示动画 `LocomotionState.Speed` 直接复制角色已按厘米 float 保存的速度。D151 已使目标动画快照使用世界水平速度，本项复用 D256a1 的源厘米 float → 米 float 算子，并由现有 provider 继续发布该值；世界速度、局部方向和 Tnua 通用投影保持原有职责。

本项复用刚在 D256a1 重新提取的同向量原生请求、响应及资产身份：133.33334350585938 和 148.5657501220703 cm/s 分别投影为 1.3333334922790527 和 1.4856574535369873 m/s。旧 `.312/.313/.433` 的运行报告当前缺失。原始厘米 float 不能由投影后的米 float 在所有输入上恢复，故 gait 和 CMC 的直接厘米消费者仍分别由 D256b/c 处理。

已写动画快照的两条原生反例，并保留 D151 倾斜角色控制。focused 测试、移除厘米 float 的消融、源码字节恢复后同启动器 target 重编、图静态审计及公共视觉 Gate 均待全部静态修复与 Bevy/依赖迁移后执行，目前尚未运行。
