# 移动基座足锁定位置

源 `ProcessFootLockBaseChange` 用双精度世界位置差和逆基座旋转计算相对位置，然后写入F32厘米缓存。`RefreshFootLock` 将该缓存提升为double，再用当前基座重建世界锁点。四组原生输入覆盖远原点、旋转、反向及不移动对照。初次基座输入使用十进制厘米，复验按实际目标基座的F32物理位置重采，两份报告均保留。

远原点的旧缓存将一侧分量从−5.07216978 cm变为−5.072212 cm。恢复厘米缓存和双精度世界更新后，四组原生读数和重锁、脱离、反向控制通过。转台原有角度断言仍采用1e−5 rad，通过F64四元数弦长判断近相等方向。

正式旋转及平移基座覆盖骑乘、跳离、新支撑、攀越、左右踏步及渲染功能。
