# 相同世界输入下的方向混合

`world.request.json` 把同一目标 0.8 世界移动输入映射到 UE，保留原地板、初始状态和 88 帧序列。原生首 PoseGait 仍为 0.07407408207654953，角色 ForwardAmount 为 1。目标为 0.07407407462596893，方向状态的前向为 0.9999998807907104。

`actual.request.json` 使用正式目标图真正收到的四组角色旋转和速度。经坐标基和单位转换，原生方向算子四组逐值复现目标公开算子。固定原生角色旋转、仅换世界速度时，原生前向保持 1。记录与边界比较见 `comparison.json`。角色旋转表示及写入路径需要继续验证。

复跑采用 `../crouch-warm-120-latest/README.md` 中的钩子以及本目录观察器和运行脚本。临时钩子已经按字节移除。
