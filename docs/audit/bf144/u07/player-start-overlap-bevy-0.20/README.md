# PlayerStart 的箱体重叠候选

本地 UE 按完整胶囊计算单壁或多壁的 MTD，再以收缩胶囊重查组合位移。fresh 原生单壁 MTD 为 10 cm，正交另一壁为 20 cm，应用后两壁均无命中。相同数据与源文件身份见 `source-identity.json`。

Avian 0.8 的场景布尔查询先传入墙体，再传入胶囊。旧目标把实际已有 0.15 cm 间隙的候选仍报告为重叠，迫使单壁试用后续双轴位移，双壁则无法发布 Ready。实际接触接口在该间隙返回无接触或负穿透。

PlayerStart 在现有场景候选中复核箱体接触的有符号穿透。正穿透继续参与原 MTD 求和和重试顺序。
