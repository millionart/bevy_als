# BF144.28 的 Avian 0.8 CCD 开关

重新读取当前 PA，21 个 body 的 `bUseCCD` 均为 false。Avian 0.8 的 `solve_continuous` 对没有 `SweptCcd` 的动态体采用默认过滤。显式空过滤在扫掠之前退出。开启的源刚体沿用原线性扫掠设置。

加载角色的自由旋转用例中，30 rad/s、1/30 s 的实际初始角速度、源一阶积分和整轮子步逐值正确。CCD 把写回前的角度从 0.9272952 rad 降到约 0.4636479 rad，solver 同时标记 `HAD_TIME_OF_IMPACT`。使用空过滤后，同一加载用例、其他积分所有者、源 CCD 开关及动态质量重建四项通过。临时分阶段观察已移除，原始失败与恢复日志随项保存。

实际倒下、接触和恢复通过现有正式 Playground 入口验证。Avian 接触求解继续由原生物理系统执行。

正式 60 Hz Ragdoll 和普通时钟 GetUp 通过功能与视觉校验。第一次普通时钟的 Ragdoll 完成倒下、碰撞、恢复，视觉护栏记录一个约 31.6 ms 的缩放落地帧，pelvis 局部位移 0.390895 m。该报告随项保留，继续在 U07 区分世界运动和骨骼空间写回。第 18 轮库测试 2094 通过、53 失败，唯一恢复为自由旋转测试。
