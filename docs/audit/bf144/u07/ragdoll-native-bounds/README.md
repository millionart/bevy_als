# BF144-D98 子碰撞体的当前包围盒

Chaos `PBDRigidsEvolutionGBF.cpp` 在宽相前积分并更新本步世界包围盒。Avian 0.8 的 `update_solver_body_aabbs` 在 Finalize 后读取实际子位姿。普通碰撞体默认采用当前包围盒加接触容差，只有显式 `SpeculativeCcd` 才采用前向扫掠包围盒。

加载角色的 head 子形体继续使用原 PA 所属刚体。以 30/60Hz 和 1/6 子步各测碰墙与自由运动。首帧按当前父位姿、子形体和 Avian 的接触边距重新计算包围盒，后续确认真实墙面冲量、受阻，以及自由运动时零冲量。该合同保留 Avian 的求解时序。旧夹具要求默认预测包围盒及第二帧停在 Chaos 的位置。

将同步移动到 Last 后，60Hz 的首帧子包围盒落后父刚体 6.25cm。恢复后四项测试通过。固定60Hz正式场景使用同一原生碰撞路径；可变帧首次布娃娃切换的 pelvis 异常仍由 U07 跟踪。
