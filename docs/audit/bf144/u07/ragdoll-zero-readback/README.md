# D116 / D117 近零缩放恢复

UE 在均匀缩放越过近零时停止物理模拟，恢复时从当前骨骼重建刚体和关节。源函数与资产证据见 `docs/audit/bf144/d116/` 和 `docs/audit/bf144/d117/`。

暂停期间动画图输出可能仍保留原 readback 配置。零尺度的父矩阵无法求逆，使用原回读会把非有限姿态写入下一次刚体重建。回读入口现在先检查实际玩家局部尺度，再调用动画图依赖的既有回读函数。保留所有非零姿态的权重和四元数处理。

单独移除零尺度条件重现 Avian 的非有限 Position。按字节恢复并用同一 target 重编后，两个加载缩放测试、零尺度停止及两项回读旋转回归通过。原来的失败、系统参数冲突诊断和恢复报告随项保留。

普通时钟 GetUp 与 60 Hz 高落地 Ragdoll 的正式功能验证均通过。第 19 轮库测试 2098 通过、49 失败、0 新增。两个近零恢复用例及此前的空中胶囊、正缩放夹具从失败集合移除。
