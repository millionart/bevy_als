# U07 1.2 m/s 蹲行反馈

保留 11 帧预热、60 帧蹲行、17 帧停止，按 UE `ComputeAnalogInputModifier` 和 `CalcVelocity` 的实际输入使用 0.8 方向幅值。两端使用各自已安装的 1.5 m/s 蹲行上限，自然达到 1.2 m/s。目标以正式 Playground 入口运行原地形、相机及角色图。补一目标普通步并按初始化相位推迟输入，完整配对 88 个原生普通帧。

88 对运动模式一致。最大世界位置差约 0.8183 mm，达到限速后的共同速度差约 7.09e−8 m/s，22 个普通帧 Root 曲线完全相等。原始姿态和曲线余差继续保留。该共同按键历史独立于旧夹具的直接速度注入。
