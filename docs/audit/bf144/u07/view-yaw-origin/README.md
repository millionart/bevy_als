# 速度相对角与 View 源精度

原88历史首个活动步的源 View 为0°。同目标世界速度的原生公共核在 View=0°得到约2.504478e−6°，仅用目标F32弧度解码的世界View便把曲线归零。此前319历史的同输入D320样本源View明确为2.5044781609e−6°，两者在目标F32表示都成为−90°。强制轴向取0°的消融使该已验实际样本失败，源码已按字节恢复。原生请求的首个资产路径失效，第二次使用本地资产实际路径通过。

仅保留源控制角时，共同世界输入的原生偏航差由77条降至24条；独立纯前向历史则暴露目标旧运动向量中的侧向误差。恢复同一源角到实际运动与停止方向后，纯前向侧向、活动速度角和偏航曲线逐值为零。两轮89行正式观察和五项相关定向证据在相邻目录。原始观察钩子按字节恢复。
