# 空中和静止保持朝向

ALS 默认空中模式及没有输入的静止 ViewDirection 保留角色旋转，只刷新目标朝向。恢复旧重建后，实际 −90° 的空中 Transform 的 w 由 0.70710677 变成 0.7071068。修复保留既有物理 Rotation 和 Transform，继续执行源允许的目标朝向与转向逻辑。

89 行正式场景和旋转定向测试通过。相比上一轮，角色实际方向 provider、完整曲线、姿态和位移逐值相同，Rig world 输入有 10 帧变化。该改动关闭直接空中保持反例。原88帧最早活动 PoseGait 余差仍需核对实际地面转向和角色姿态表示。复跑使用 `../crouch-matched-input/` 的同一只读观察器。
