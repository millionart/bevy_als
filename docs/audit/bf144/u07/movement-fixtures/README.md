# 移动回归的实际碰撞输入

- Perch 和 Line 保留真实宽扫命中点与时间，沿真实的 Tnua 0.33 basis 配置再验普通支撑和墙侧拒绝。
- 低输入楼梯正距离命中在源拉回后仍无有效前进。高输入控制仍越过多级楼梯。
- CMC 事件按同一帧读取，布娃娃按 None 模式测试退出请求。陡坡测试以源扫掠产生的横向偏转证明实际接触。
- 走离测试的阻挡墙明确拒绝 StepUp，避免把跨步下扫误作平墙截短。完整前进、失去支撑、余时与实际偏转分别保留。
- 有效阻挡地形高出支撑时，跨步回滚或向下落在源允许域。步后查询保留平地支撑、无穿透及碰撞拉回的允许高度。
- Roll 输入时机检查实际动作是否被预先接受，源地板与胶囊交接由 D52 和各自走离测试覆盖。
