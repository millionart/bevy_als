# 楼梯终点与末步碰撞

终点通用胶囊扫掠的三角面距离为 0.02383995 m。角色实际使用的缩短胶囊及 Perch 地板查询得到同一楼梯的可站立支撑，终点与查询中心的高度差为 0.0240014 m。用角色查询校验楼梯支撑，并验证无穿透和终点位于墙前。正式 Playground 通过三座楼梯六条双向路线。

同批独立原生扫掠在 0.10 m 范围未命中，在 0.15 m 和 0.20 m 范围命中 14.999998 cm。目标查询的接触点及法线仍在同一墙面，距离等于 0.15f32 的下一可表示值。修正几何见证上界后，100 ms 和 125 ms 的末步位移、速度和连续消费断言均通过。

原生报告同时保留后续地板调查所用的缩短胶囊控制。
