# D73 活动布娃娃缩放复验

本地 UE `FBodyInstance::UpdateBodyScale` 使用活动胶囊轴长及半径下限。沿原请求重读实际质量、质心和惯量，四档 `physics_body_probe` 与 D73 既有报告逐字段相同。几何预期来自原 PA 和该源函数的尺寸公式。

Avian 0.8 插入颈部胶囊时，以旋转矩阵的列长得到约 0.99999994、0.99999994、1 的缩放，暂时生成凸包。实际 `ColliderTransform` 传播采用局部 scale，恢复单位胶囊。受控程序的单位四元数及颈部旋转对照保存在同目录，覆盖传播前后两阶段。

加载测试现在先执行一轮应用调度，再使用实际四档缩放及原生质量断言。活动缩放、小尺寸初始化和已分离播放器三项均通过。旧测试和新增含具体形体的失败记录同时保留。
