# BF144-D255a 地面制动乘积精度

fresh UE `ApplyVelocityBraking` 使用 double `FVector` 计算反向加速度、每个 float 步长的乘积及子步累计。目标此前在每次乘法和累计后降为 F32。本项在制动循环内保留 double，最终回写速度时才投 F32；既有停止与反向判断仍使用目标原有 F32 边界，输入加速乘积留给 D255b。方向归一化继续复用 D265 的结果及其已知 F32 消费边界。

fresh native reader 对共同输入重采轴向、反向、零步长、摩擦子步、停止和 D265 小侧向控制。首例从 0.9856696724891663 m/s 制动到 0.48566964268684387 m/s；摩擦子步结果为 0.4831782579421997 m/s，小侧向源结果与 D265 的既有反例一致。请求、原生结果、资产身份和 watchdog 见本目录；旧 `.310` 原始报告当前缺失。
