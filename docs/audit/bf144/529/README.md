# BF144.529 状态同步实际低台来源

同一 Playground 对 20.5 cm、21.5 cm 原案、21.5 cm 抬台和 22.5 cm 四案取证。以生产函数生成只读重放，三处位置为状态同步前、目标撞墙拉回停止点及源原生停止点映射。12 次基准重放均与相同位置的公开查询逐值相同。原生实际 Landed 和 floor 数据沿用 .528。

21.5 cm 原案在两个停止点均先胶囊命中墙顶，短射线把法线修为 Up，窄胶囊支撑检查通过，最终仍保留墙顶。目标滑动后的状态同步位置则由第一次胶囊扫掠直接选中低台。20.5 cm 三处保墙顶，抬台与 22.5 cm 三处均直接选低台。四案在源停止点的目标选中对象与原生一致。12 次实际结果均为胶囊路径。

关闭中心射线或 perch 不改变本批结果；关闭短射线后，原本选墙顶的位置改为低台。只有诊断关闭短射线后，20.5 cm 帧末才出现中心射线低台，实际状态同步未走该路径。四案关键帧与旧报告一致，三份完整参数逐字节相同，抬台案最早从第 54 帧起有差异。共用 Rig、骨架、配置和自测沿用 .522 的相同证据。
