# BF144.517 帧末走离与零余时

复用 .516 已读取的同几何 UE 矩阵，并在可见 Playground 运行同台宽与同一个 60 ms 长帧。半宽 85 和 90 cm 都在第 48 序号末步切 Falling，竖直速度为零，第 49 序号才出现重力积分。100 cm 在第 48 序号都保持 Walking。

80 cm 在 UE 首步后走离，在当前 Bevy 末步后走离。用同一时钟和速度从首步走离样本复算交接位置，分别只平移目标起点 1.22 cm 或将其预期首步落点对齐。两次都改为首步走离。撤掉控制后目标报告逐值恢复。证据将这个时点差限定为对进入子步的位置敏感。

100 cm 在下一帧走离时，UE 竖直速度为零，目标出现向上 0.303953 m/s。物理生产阶段另行归因。八次可见功能通过，截图为零。
