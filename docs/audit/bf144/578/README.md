# BF144.578 q45 制动帧的高度写入

沿用原生台外轨迹与前向、方向和 q52/53 高度控制。q44 两端高度几乎一致。q45 松开输入，三子步只有首步移动。Bevy 的完整胶囊下扫先给出 2.424149 m 的候选，再由短胶囊的带外调整写入 2.42155957 m。物理前后位置逐值相同，竖直马达只抵消重力。

对同一盒体、起点与胶囊复跑 Chaos。完整下扫比目标长约 149.2 µm，短下扫长约 59.6 µm。在同一实际候选位置只替换短下扫距离，保持带外判断并恢复 q44 高度。真实对照在 q45 保留原带内高度，从该帧到 q57 与原生高度差小于 0.5 µm，竖直速度与落地帧一致。

前置固定间隙归 D273，实际留下的 59.6 µm 归 D125。两组公共功能报告保留 572 的骨盆告警。本次只核对 q45 写入和继承路径。截图 0，性能验收暂停。
