# BF144-D22 空中子步的极小水平速度

fresh UE `PhysFalling` 在每个未落地子步末将水平速度平方与 `UE_KINDA_SMALL_NUMBER * 10` 比较；源单位 cm/s 换算到目标 m/s 后的平方阈值为 `1e-7`。fresh 原生 60 ms 双子步样本中，单轴 0.20 mm/s 与双轴各 0.22 mm/s 的末速度清零，双轴各 0.23 mm/s 保留，三组竖直末速度相同。请求、原始结果和源常量保存在本目录。

目标只在非着地 Falling 子步末执行该水平清零并保留竖直速度；已写单/双轴、阈值附近、两子步位移和加载角色发布对照。历史目标报告 `target/bf144/06/tiny_velocity/` 已缺失；测试、消融、图审计和真实 Playground Gate 待全部静态修复及 Bevy/依赖升级后执行。
