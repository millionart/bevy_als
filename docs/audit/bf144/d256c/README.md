# BF144-D256c CMC 速度长度阶段

fresh UE `CalcVelocity` 对转向的 `VelSize` 和超速加速的 `NewMaxInputSpeed` 均将 double 厘米向量长度存为 float，再供 double 向量计算。本项在目标地面核保留这两个厘米 float 阶段，并以 double 米制参与转向和限幅；输入世界向量仍为目标已有 F32。加速与制动的其他 F32 乘积仍归 D255。

本轮 native reader 对三组转向、两组超速限幅、无转向和零步长采样；速度、加速度、摩擦、最大速度和步长均保存在请求中。共同输入的轴向加速度和步长使加速乘积精确，便于隔离长度阶段。首组原生长度为 494.8538513183594 cm/s，源计划速度 X 投米 float 为 −0.8444546461105347；其余原生输出及长度均在 `velocity.native.json`。这些是受控共同输入，不冒称原自然运动轨迹。旧 `.440` 原始报告当前缺失。

已写七组生产地面核的原生值及控制，并保留 D265/D266 的方向、转向和实际 motor 夹具。focused 测试、厘米 float 阶段消融、源码字节恢复后同启动器 target 重编、图静态审计及公共 Playground Gate 均待全部静态修复和 Bevy/依赖迁移后执行，目前尚未运行。
