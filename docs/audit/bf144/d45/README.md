# BF144-D45 空中翻滚根运动保留竖直速度

fresh UE 源显示 Falling 使用动画根速度时保留已有重力轴速度，再继续 Falling 物理；fresh 原生设置允许翻滚进入空中继续，Roll 序列开启根运动。通过仓库原生读取器采样 46 个 30 Hz 根轨道帧，源竖直 Z 均为零。请求、源摘录、原生结果与哈希保存在本目录；设置读取与 D43 逐字节相同并共享其 Git 文件。

目标 Roll 驱动在 Air 时对物理速度和 CMC 写回速度均保留输入竖直分量，地面根运动路径保持原语义。已写带非零根竖直分量的系统对照，以及加载角色在 −2/0/+2 m/s、16.667/100 ms 下的整帧对照；测试、消融和动画公共视觉 Gate 待统一验证阶段执行。

本项使用项目当前默认 Y 轴重力语义，自定义重力方向未在本反例扩展。旧清单所引 `target/bf144/15/initial/` 已不存在，其原始报告缺失。
