# BF144-D253 地面计划位移与物理子步

fresh ALS 源码在本例中以一个 CMC Walking 步执行计划位移。当前 Avian 0.7 在默认六个物理子步中分别累加 F32 `SolverBody.delta_position`，之后才写回世界位置。`.441c` 封存的实际计划速度/位移及独立六步 F32 复算见 `witness.json`：X 计划位移为 0.02222222462296486 m，六步模型为 0.02222222276031971 m；`.501` 的源位置、时间和速度另以原始记录引用。旧 `.307/.434` 原始报告当前缺失，不把上述模型称为新的实际运行观测。

本项在 Avian 子步结束、SolverBody 写回前，仅对 Grounded、单 CMC 步、静止支撑、相同帧/物理时钟、无阻挡接触及无旋转的角色处理：计划速度与位移必须一致，最终速度及实际累计也必须逐值等于该计划的无阻挡子步模型。满足时将水平累计设为本帧计划位移，保留竖直位移。普通 Avian 积分与项目的 `SourceCharacterFullFrame` 路径分别按实际子步时钟复算；传感器接触不视为阻挡。全局子步数、其他角色及不满足条件的碰撞、约束和移动支撑路径保持原处理。

已写六步、两种积分路径、阻挡、传感器、移动支撑、旋转及其他自定义积分控制。focused 测试、移除末端计划位移的消融、源码字节恢复后同启动器 target 重编、图静态审计及公共 Playground Gate 均待全部静态修复和 Bevy/依赖迁移后执行，目前尚未运行。Bevy/Avian 迁移后须重新核对本项调用的调度与碰撞接口。
