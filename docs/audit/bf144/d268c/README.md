# BF144-D268c 地面动力曲线的厘米求值

本轮 fresh 原生 Normal 制动轴在 gait 1.1131258010864258 和 1.7916673421859741 分别返回 1471.718505859375 和 1302.0831298828125 cm。请求、原生读数、watchdog、源资产身份、ALS/UE 求值路径及 `.441b/.441c` 证据见本目录。D267 已提供九轴源键，Sluggish 加速切线经 SI F32 回转会丢一ULP，因此不能只把旧 F32 配置乘100。

生成器离线将源键投为 SI F64；`HermiteKey` 的 value/tangent 从 F32 拓宽为 F64，仍表示 SI；运行时把键投到厘米 F32 后按现有曲线算序采样，所得加速度/制动再投 SI F32，摩擦保持原单位。自定义 SI 键也走同一数值阶段；动态结果仍是既有 `GroundedDynamics` 的 F32 接口。公开键字段类型拓宽会影响显式赋入 F32 变量的 Rust 调用方，仓库内已调整；上游/外部调用需在迁移验证时检查。Hermite 展开算序 D206 和源速度生产 D256 仍独立。

`configuration-diff.json` 保留 D267 后到当前目标配置的6个 F64 精度字段变化，全部投 F32 不变；旧 D267 报告保持历史原样。项目根目录运行 `pwsh -NoProfile -File docs/audit/bf144/d268c/generate.ps1` 可重生成当前目标配置和报告。已写两组原生输出、旧SI阶段对照、Sluggish精度及生成器用例。
