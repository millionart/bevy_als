# BF144-D32 缩放胶囊脚底的基座角速度

fresh UE 源以世界缩放胶囊半高和重力方向得到脚底，再将脚底相对基座的位置与物理角速度叉乘；fresh 原生角色默认值确认角速度和三个线速度轴均允许继承。请求、源摘录、原生数据和哈希保存在本目录，解压数据已逐字节核对。源原生读取器本次没有驱动旋转刚体，实际旋转平台结果依源算法推导。

目标地面支持和离地继承共用脚底计算，现在读取角色当前直接或父级世界缩放；新系统级反例覆盖站立/蹲姿、直接/父级缩放、无角速度和竖轴角速度。缩放表示遵循项目现有的角色地面尺度约定。旧清单指向的 `target/bf144/11/jump_and_permissions/` 已不存在，其原始报告缺失；新增测试、消融及真实入口 Gate 待统一验证阶段运行。

本项仅修改动力系统的共享脚底，不扩展到同帧落地后再次离地的物理胶囊 AABB 路径；该路径尚无本项反例证明。
