# BF144-D11 非均匀缩放的物理胶囊

fresh 原生角色读取确认胶囊半高 90 cm、半径 30 cm。UE 物理 Sphyl 创建和动态重缩放均取水平绝对尺度的较大值并按竖直半高约束半径；创建时最小轴半长为 0.05 cm，已有物理状态更新时为 0.0001 cm。源动画预测及地面查询则读取 `GetScaledCapsuleRadius` 的较小水平轴；源代码和 Avian 0.7 的碰撞形体缩放、质量更新时序证据保存在本目录。

目标根据世界尺度和姿态同步圆形物理胶囊，在 Avian 缩放与质量计算之间恢复源形体并更新质量属性；物理准备前也同步一次以供 CMC 移动扫掠。动画预测改用源逻辑查询胶囊，避免误用较宽的物理形体。已写直接/父级缩放、站立/蹲姿、半径约束、创建/后续缩放、质量属性、加载角色步行/落体扫掠及动画预测形体测试。旧 `target/bf144/04/scale/` 报告已缺失；目标测试、消融、图审计和真实 Playground Gate 均待全部静态修复及 Bevy/依赖升级后执行。
