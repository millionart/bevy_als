# BF144-D17 首次陡坡碰撞的空中输入限制

fresh UE `PhysFalling` 在首次碰撞后先计算不含空中输入的速度，再按 `LimitAirControl` 去掉压入向上斜面的水平输入，最后对剩余时间计算滑动；初始穿透仅允许朝外输入。fresh 原生 60° 斜面四组分别使用朝内、朝外、沿面和无输入：朝内与无输入的碰撞后竖直速度均约 −87.2625 cm/s，其他两组保留源方向效果。原始请求、四组角色状态和命中、源代码与 reader 身份保存在本目录。

目标将已有二次碰撞的相同输入限制提取为共用函数，并在首次碰撞的无输入速度上应用源规则；没有输入时保留原路径。已写规则边界、四组原生速度及加载角色 CMC 事务对照。历史目标报告 `target/bf144/06/air_control/` 已缺失；测试、消融、图审计和真实 Playground Gate 待全部静态修复及 Bevy/依赖升级后执行。
