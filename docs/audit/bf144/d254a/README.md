# BF144-D254a 普通地面速度快照

fresh ALS Walking 源码以 double 世界位置差和本步时长回算速度。目标 D264 已在物理前使用计划速度，但物理后快照仍以 F32 世界位置差回算。此前封存的 `.501` 实际第 99 帧中，源速度投影等于目标计划速度，而目标 −15 m 世界位置差产生不同的已发布速度；`witness.json` 保留同帧源/目标位置、计划和时间，引用原始证据与哈希。

本项仅在 Grounded、单 CMC 步、相同物理时钟、零支撑速度、计划位移等于计划速度乘步长且实际水平终点等于计划终点时，在快照保留同帧计划速度。阻挡、实际终点不同、移动支撑及时间膨胀继续按实际位置回算；不声称一般碰撞路径或极大世界坐标已达到源 double 精度。落地余步与多 CMC 步的内部回算仍是 D254b，D253 的物理子步累计仍独立。

已写原点、非零原点、`.501` 双轴、阻挡、不同步长和移动支撑的快照用例。旧 `.308` 的原始报告当前缺失。focused 测试、恢复 F32 世界差分的消融、源码字节恢复后同启动器 target 重编及公共 Playground Gate 均待全部静态修复和 Bevy/依赖迁移后执行，目前尚未运行。
