# BF144.540 跨步后重查扫掠距离

沿用 .539 的自然跨步和源间隙控制，在真实状态同步之前记录缩短胶囊扫掠、命中双方见证点及主台尺寸。生产 floor 的重放和公开查询逐值，现场碰撞事务、解算与两帧状态记录中的关键第 40 帧同 .539。两案都是一次宽胶囊命中，选中主台。

以目标实际胶囊尺寸、主台尺寸、相对位置、方向和扫掠长度直接送入原生 Chaos。世界与盒相对两种表示的扫掠距离逐值一致。自然案 Chaos 8.40157604 cm，目标 8.37850571 cm；源间隙案 Chaos 7.07287693 cm，目标 7.04804286 cm。相差约 0.231 和 0.248 mm，与目标见证点的实际分离相符。
