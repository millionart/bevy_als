# BF144-D38a 下落阻挡撞击力

fresh UE 源显示非落地的前两次 Falling 阻挡分别触发 HandleImpact；原生 CDO 为 InitialPushForceFactor 500、PushForceFactor 750000、速度缩放开启、质量缩放及 Z 偏移关闭。源默认及既有 `docs/audit/bf144/570/` 的本机证据均为静止撞击使用力而不是冲量。源以 cm 为长度单位：目标分别生成 5 N 和 7500 N，静止分支再乘 30；1 cm/s 的逐分量静止阈值生成 0.01 m/s。请求、源摘录、原生读取、生成报告与哈希保存在本目录。

落地和地面扫掠分别由 D38b、D38c 处理。超过物理帧限制后由 `source_physics_timing` 执行的额外 Falling 扫掠当前不发撞击事件，多子步力缩放也缺少本项运行证据；这些边界需在统一验证阶段以可复现反例复开，而不能视为已验证。
