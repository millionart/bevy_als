# BF144-D254b 落地与多步 Walking 的速度回算

fresh ALS Walking 源码以 double 厘米世界位置差除以本步时长。目标 `walking_movement_transaction` 先将位置写入 F32，再以位置差回算，`.576` 封存的正负落地余步因此分别损失约 20.53 和 23.95 µm/s。原观察确认该 Walking 余步的前向扫掠没有命中；`witness.json` 保存两侧源落地及目标起点、计划、请求位移与发布速度。
