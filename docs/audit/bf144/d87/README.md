# BF144-D87 Ragdoll线性阻尼

fresh PA读取的21个body线性阻尼均为0.01，`p.LinearEtherDragOverride=-1`；结果与受跟踪的D65a原生输出逐字节相同。源先把加速度与冲量加入线速度，再乘`max(0, 1 - damping * dt)`，最后更新位移。请求、reader报告、原生身份、每个body的值及fresh源/目标调用片段已保留；旧 `target/bf144/26/initial/` 缓存缺失。

Avian在积分时先乘缓存系数再加预计算增量；目标只对真实Ragdoll的动态body，把缓存系数和已经累积重力及世界外力的增量同时改为源乘数。本地力和直接冲量在该乘数之前加入速度，因此同样被阻尼；自定义速度积分所有者和普通刚体保持原路径。已写加载spine的帧时长、零/原生/截断阻尼、速度、重力、世界力、本地力及冲量对照，以及普通刚体和自定义所有者控制。

测试、去掉该适配的消融、接触轨迹和真实Playground均待统一Gate；运行时修改源全局阻尼覆盖值的模式不在当前native设置范围内。
