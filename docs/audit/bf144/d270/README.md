# BF144-D270 移动世界输入的多余归一化

本轮原生四组45°输入覆盖零、单位、超幅和模拟量；请求、输出、watchdog、源资产身份及 fresh ALS/UE 输入 clamp 与 CMC clamp 代码见本目录。单位前向的原生方向长度小于1，CMC 保留该值；既有 `.442b` 固定该输入后还验证公开运动核的消费差异。

`view_relative_move_input` 对二维输入先做最大长度1的限制，再按源基旋转，不额外单位化世界输入；实际 Tnua 输入直接消费该向量。`view_relative_move_direction` 继续提供方向查询需要的单位向量，停止链接和视觉方向对齐的合同不变；原 Playground 的相机输入探针改用带幅值入口。D269 的源三角近似与 D265/D266 的双精度 clamp 阶段仍独立。
