# BF144-D49 空中 Roll 短帧使用 midpoint

fresh UE PhysFalling 源以根运动应用前后速度的平均值积分位置；Avian 默认位置积分使用末速度。fresh 原生角色在初始竖速零、重力 −981 cm/s² 时，16.667/25/33.333/50 ms 的下降距离分别为约 0.13625/0.30656/0.545/1.22625 cm，均与 midpoint 公式一致。原始请求、逐帧结果、源码、reader 身份和无损压缩哈希保存在本目录；源 Roll 根轨道事实复用 D45。

目标空中活动 Roll 在短帧也启用已有角色 midpoint 物理路径，非 Roll 短帧保留既有路径。已写启用条件、加载角色短帧/长帧及无 Roll 对照；测试、消融和动画公共视觉 Gate 待统一验证阶段执行。原生样本验证 Falling 公式，本次未在源端播放 Roll 进行组合采样。
