# 空中 Roll 落地

实际 50 ms、5 mm 落地夹具中，Avian 的预测接触先把竖直末速降至约 −0.15 m/s。项目自己的扫掠随即只推进 3.75 mm，漏过地面，之后才由求解器接触发布 Grounded，离地高度只有 1.249969 mm。原生同输入 5 mm 确实碰地，20 mm 不碰地。将角色的 SpeculativeCcd 设为零仍受 Avian 全局接触容差影响，失败逐值保持。

仅在项目接管空中动画根运动的位置积分时，现有角色接触阶段在约束生成前丢弃尚未接触的点。实际接触保留。去掉该条件，旧 1.249969 mm 稳定复现。正式 Locomotion 的实际图、Fall、预测与各落地阶段通过。
