# BF144.514 D07 实际运动阶段对照

UE 的 ControlledCharacterMove 以进入帧时的最大加速度缩放玩家输入，随后 PhysWalking 刷新动力曲线。在 Sprint 的第 26 序号，UE 以旧值 20 m/s² 积分，刷新值为 16.972292 m/s²。Bevy 的 Normal 对照用本轮刷新值 16.971708 m/s² 生成计划。

目标观察在原地面 motor 刷新前读取旧值，在原 motor 与碰撞事务之间复用生产速度步。观察先确认单子步、静止基座、当前起点和原计划，再仅在见证帧把旧值复算的计划交给原碰撞事务。当帧刷新曲线仍供动画读取。目标实际纵向速度由 4.565763 增至 4.666728 m/s，UE 对应值为 4.666667 m/s。Sprint 混合保持全权重，加速动画时点变化，最终 Root 有 73 个骨骼记录改变。

初版调度探针把延续的上一帧地面起点当成未执行条件，触发断言。最终探针使用实际帧前快照。去控制后见证帧全部逐值恢复，整段报告从序号 35 起保留物理末位差。
