# BF144.538 成功 StepUp 后的物理再碰撞

复用 .537 的 145 cm 宽台、侧凸台、50 ms 第 40 帧和原生结果。UE 在抬高位置完成前向移动再下扫，帧末没有横偏。目标实际 CMC 候选有效，但把预碰撞推进位置设到下扫高度，并交给 Tnua 马达水平余量。

三案的 CMC 重放、真实事务、马达及解算入速相同。基线和恢复案有侧凸台约束，第一子步横向速度约 −0.610 m/s，六子步后横移约 −2.885 cm。只在 CMC 完成后屏蔽凸台的碰撞层，解算阶段没有凸台约束，六子步横向速度近零，水平终点与原生一致。记录相位的 ContactGraph 没有保存逐点冲量，归因依据是相同入速、单凸台控制及实际解算位移。关闭屏蔽后完整参数与有效基线逐字节一致。屏蔽后的高度余差约 2.52 mm，另作取证。已确认的水平差归 D297。
