# BF144.508 VelocityBlend 半衰期配置

AB_Als 原生 CDO 使用 AIS_Als_Default。其 Grounded VelocityBlend 半衰期是可编辑 Float，默认 0.1 秒。现有 Bevy 导入输出 Grounded 的 Yaw 曲线，实际 RefreshGrounded 直接以 0.1 秒更新四向权重。现有默认设置通过相同半衰期核对。

隔离诊断包复制每个原生实例的 Settings，仅覆盖该 Float。五组各 48 帧采用相同控制输入、物理轨迹、速度、朝向和步长。省略与显式默认输出逐值相同，0 与负值输出逐值相同，0.4 的权重更慢趋向同一目标。正值独立复算使用零值组的实时目标，三组共 576 字段精确。零值与 0.4 秒组各有 35 帧本地姿态变化。负值通过诊断直接写入以覆盖源非正值分支，编辑器元数据限制最小值为零。

Bevy 可见 Playground 的第 32 个运动场景序号选用当前生产 Grounded 刷新。一次诊断只让原刷新在同输入上走既有立即取值分支。常量阻尼与立即取值分别符合独立候选，去掉控制重新运行后参数报告逐字节相同。

`prepare_reader.py` 在临时目录生成隔离诊断源码。去掉唯一字段写入时，零值请求读回默认半衰期并得到默认轨迹。恢复源码原字节并重编同包后，零值轨迹恢复。首个诊断包保留源码哈希、构建和运行报告，二进制哈希从消融版开始记录。原读取器兼容复验使用省略选项的同一请求。截图为零，性能验收暂停。
