# BF144-D25 站起净空的重力朝向

fresh UE `UnCrouch` 的首次与贴地重试净空均使用 `GetWorldToGravityTransform()`；默认重力下该变换为 identity，而实际组件位移仍保留组件世界旋转。原生几何探针用短扫掠检测初始重叠：直立站姿胶囊避开侧墙但与顶板重叠，60° 倾斜胶囊则撞侧墙且避开顶板。倾斜组通过共同变换障碍物和方向到胶囊坐标得到等价结果。

目标两处站起净空查询改为默认重力朝向，实际 actor 旋转及写回不变。已写加载角色的侧墙、顶板、父级、直立、无障碍和 Grounded 降低重试对照。历史目标报告 `target/bf144/08/tilted_initial/` 已缺失；测试、消融、图审计和真实 Playground Gate 待全部静态修复及 Bevy/依赖升级后执行。
