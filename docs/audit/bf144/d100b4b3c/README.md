# D100b4b3c 按源形体访问网格

源箱体沿用两轮访问。首轮按采集序调用面接触计数为零的三角，记录已访问，包括没有生成点的情况。第二轮依同一顺序只调用尚未访问且计数小于三的三角。计数来自当前面边点数及该面三个 cooked 顶点的面点所有权，每次访问前重新读取，第二轮新增的边点也会影响后续三角。

生产接线时复读 `ConstructQuadraticConvexTriMeshOneShotManifold`，确认胶囊覆盖为单轮访问和 double `0.9999` 面法线阈值。箱体保留 float `0.998` 提升到 double 的阈值。旧源闭包只读生成器构造默认值。补充入口证据保存在 `shape-source-facts.json`，由 `tools/import/import_mesh_contact_quadratic.py` 生成胶囊阈值。两种阈值同时用于面点登记和法线修正。

目标使用 a 的源采集序和 b 的即时所有权状态。箱体控制覆盖共享边延迟、三点跳过、空输出只访问一次及第二轮动态跳过。胶囊控制覆盖已有三个面点仍访问，并比较点积 `0.999` 在两种形体下的登记及修正。编译、测试、消融和 Playground 待统一 Gate。
