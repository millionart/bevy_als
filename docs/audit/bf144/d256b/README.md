# BF144-D256b gait 消费源厘米速度

fresh `UAlsCharacterMovementComponent` 从世界水平速度求出厘米 float 后，直接将它送入三段 gait 范围映射。D256a 提供的米制 float 是为运行时公开接口投影的值，双轴速度可能无法通过乘 100 恢复原始厘米 float。

三组受控双轴速度的 fresh 原生长度与范围映射记录在 `mapping.request.json` 和 `mapping.native.json`。首组源值为 452.5613098144531 cm/s、gait 为 2.282041072845459；经米 float 往返为 452.56134033203125 cm/s、gait 为 2.282041311264038。其余两组也有不同的映射结果；这些是受控共同输入，不冒称自然场景帧。先前 `.441c` 的 240 帧证据仍按相对路径引用，旧 `.433/.440` 原始报告当前缺失。

gait 状态、地面动力、停止预测及落地后的地面动力均从各自世界速度直接得到源厘米 float，再复用同一映射；原公开米制标量接口及其既有行为保留。自定义阈值的源厘米精度和 CMC 转向分别保持独立边界。已写原生双轴值及实际 gait 系统反例；focused 测试、米制往返消融、源码字节恢复后同启动器 target 重编、图静态审计和公共视觉 Gate 均待全部静态修复及 Bevy/依赖迁移后执行，目前尚未运行。
