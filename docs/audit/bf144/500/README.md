# BF144.500 VelocityBlend 的实际输入与历史

世界位置和速度采用已核验的厘米到米与坐标基反射，身体基另由源 X 前向与目标负 Z 前向对应。分别固定原生或目标算子，交叉两端的实际速度、身体旋转和上一权重。固定前态读每个观测帧的真实上帧。连续回放只在第 99 帧取起始种子，此后按对应输入组合推进。两种原实际组合都逐值复算。

第 104、106 帧固定前态的整组输入互换能双向恢复对端权重。第 104 帧三个独立输入替换均有变化，前态影响最大。连续组合保留第 99 帧起始差异，也反映后续速度与旋转。个别组合仍受原生算术中间舍入的不确定范围影响。种子差异的来源另核。

设置 ALS_UE_SOURCE_ROOT 后，执行 `run_python.ps1 -Name prepare` 和 `run_replay.ps1 -Label baseline -Build`。令 ENABLED_FACTORS 为 3，再跑 `no-history-input`，目标固定与连续端点应共 22 次失配。恢复源码字节同库重编后，`restored` 与基线字节相同。
