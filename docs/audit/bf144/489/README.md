# BF144.489 D278 足锁定与 VM

使用 BF144.487 的生产源码摘录、锁定前态和真实 VM 复算。保持足位置和每帧实测前态，分别只单位化受影响的实际 Q，以及替换为 BF144.488 父骨等轴对照的 Q。两组 VM 都在同一份实际前态的克隆中运行，以原场景几何重新求交。角度取两个四元数单位化后的最短旋转距离，四元数分量和 F32 局部姿态另行逐值核对。

在仓库根目录设置 ALS_UE_SOURCE_ROOT，执行 `run_python.ps1 -Name prepare` 和 `run_replay.ps1 -Label baseline -Build`。把 `uniform_q` 的读数换成 `actual_q` 后重编运行 `no-rotation-toggle`，两组替换应归零并触发断言。恢复原字节重编后，`restored` 三份报告应与基线字节相同。

父骨等轴结果在此仅用于提供受控的旋转输入。保持实测足位置，因此有意隔离了完整父骨缩放变化会带来的位置影响。连续反事实传播另核。
