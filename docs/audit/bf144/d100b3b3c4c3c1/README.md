# BF144-D100b3b3c4c3c1：源碰撞候选发现边界

fresh Barrel/foot 原生样本中，2.4 cm 间距激活 4 点，3.5 cm 间距没有激活约束。目标静止窄相位只以 0.5 cm 预测距离查询，因此前者无法由目标原始接触生成；实际求解器测试已写，尚未运行。请求、原生报告、目标 bounds 和哈希见 `native-identities.json`。

重新读取的源事实表明，当前非 MACD、bounds 检查启用时，源先将动态 shape 的世界包围盒按源 cull 扩张，再与凸包世界包围盒相交。目标 `ColliderAabb` 每侧增加 0.5 cm 后，建树使用的 `EnlargedAabb` 初次还会增加 5 cm；因此本样本的初始扩展树边界相交，不能据紧包围盒推断整个目标碰撞对缺失。该缓存是随运动更新的，不能以初始值推断所有后续帧。具体源码摘录与哈希见 `target-facts.json`。

先前提出的源碰撞树包围盒抽象缺少实际需要的证据，已撤除；剩余问题是目标碰撞对存在但没有 manifold 时也要按源几何判定接触。bounds CVar 的直接原生值仍须在 reader 重建后采集；源接触缓存与窄相位生命周期的接入另列后续子项。所有测试、消融、全量转换 diff 和 Playground 均待统一 Gate。
