# BF144.515 D07 两子步地面事务

源角色以与 .512 相同的输入进入 Sprint，第 26 序号改用 60 ms。UE 的旧加速度为 20 m/s²，刷新后为 16.972292 m/s²。按两个 30 ms 子步复算，末速与实际 5.200000 m/s、位移与实际 0.294000 m 一致。

目标复用 Normal 对照和同一长帧。两个版本在原地面事务前分别替换外层计划、或只替换该事务的加速度。外层计划控制产生不同计划，事务后及见证帧输出逐值相同。事务控制保留原外层计划，实际末速由 5.018330 变为 5.200037 m/s，位移由 0.285826 变为 0.294003 m。事务后立即恢复刷新值，Standing 读到相同的最大加速度。Sprint 有效权重保持 1，时点和最终 Root 的 73 个骨骼记录变化。

去掉控制后见证帧逐值恢复，完整轨迹从序号 28 起有末位差。本轮覆盖固定地面、无模式切换的两个子步。
