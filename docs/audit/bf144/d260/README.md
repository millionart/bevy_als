# BF144-D260 足锁定角度换算

fresh UE 源码将 float 弧度乘以由 float `UE_PI` 计算的系数 57.2957763671875；Rust 的 `f32::to_degrees` 使用 57.295780181884766。本项仅调整足锁定旋转限位的弧度转角度，不推广到其他尚未经共同输入证明的调用。Atan2 算法仍属于 D259。

旧 `target/bf144/420` 的四份报告当前缺失。`source-facts.json` 引用 D262a fresh 原生 `controlled-limit-1` 请求和响应：同一原生弧度换算得到 56.99893569946289，旧系数得到 56.998939514160156。真实前态构造的受控阈值 56.998836517333984 使两种系数分处限位判断两侧；测试使用相应运行时坐标的四元数，并从公开限位函数检查结果。

该 focused 用例、旧系数消融、源码字节恢复后在启动器同 target 重编、图静态审计及公共视觉 Gate，均在全部静态修复和 Bevy/依赖迁移后执行，目前尚未运行。
