# BF144-D151 动画速度取世界水平面

fresh ALS 源码从角色世界速度的水平面求 Speed，`bMovingSmooth` 比较该值和默认设置的 150 cm/s；Standing 源图将该标志用于状态转移。目标动画快照原先取角色前/右局部投影的长度，倾斜角色会丢失水平速度分量。本项只将 ALS 动画快照的 `horizontal_speed` 改为世界 XZ 长度，保留局部方向及通用 Tnua 投影能力。

fresh `speed.request.json` 对同一世界速度提供直立和 60° 倾斜旋转，并读取源水平长度与默认设置：两种输入均为 160 cm/s，超过 150 cm/s 阈值；80 cm/s 和零速为控制。该 geometry probe 的长度来自给定世界向量，并不驱动源角色或声称执行了 Standing 状态机。源 Standing 图及历史 240 向量长度证据按 `source-facts.json` 引用；旧 `.311/.313/.433` 运行报告当前缺失。

已写实际动画快照系统的直立/±60° 倾斜反例，检查世界速度、移动判定及局部投影仍然保留。源厘米 float 的舍入阶段是后续 D256，不在本项混入。focused 测试、恢复局部投影的消融、源码字节恢复后同启动器 target 重编、图静态审计及包含倾斜角色的公共 Playground 验证均待全部静态修复与 Bevy/依赖迁移后执行，目前尚未运行。
