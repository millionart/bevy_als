# BF144.558 第二次碰撞后加回离墙输入

复用 557 的竖直墙和 60° 不可走坡，保留 q49 的 50 ms、角色初态和重力。两组只切换空中输入方向。原生两组都实际先撞直墙、再撞坡面。

UE 第二次偏转先去掉空中输入。受限输入与第一面墙法线点积为正时，按剩余时间加回。正点积组实测获得约 0.03079 m/s 的离墙速度，并在余时离开第一面墙约 0.938 mm。负点积组未加回，复现 557 的原生读数。实际速度和第二次停止点到帧末的位移均可从原生输入、法线和余时复算。

Bevy 生产路径和仅去输入的重放都缺少正点积组的离墙速度。保留原有两次命中，仅加入该条件的只读重放得到约 0.03085 m/s，完整速度向量与 UE 相差小于 0.001 m/s。负点积组的条件重放与仅去输入重放结果相同。两组功能 Gate 通过，实际物理解算运行生产路径。证据补入 BF144-D307，截图为 0，性能验收暂停。
