# BF144-D256a1 物理实际速度的源单位舍入

fresh ALS 源码先以 double 厘米世界速度计算水平长度，再将厘米速度存为 float。目标此前直接计算 float 米制长度。本项为 ALS 运动生产者加入这一源阶段：世界水平速度先升 double 并换算厘米、求长度后投 float，再以 double 除以 100 投回公开米制 float；原始世界速度向量不变。角色移动判定也消费同一源阶段。

fresh 原生同向量样本确认：1.3333333730697632 m/s 对应厘米 float 133.33334350585938，投影为 1.3333334922790527 m/s；实际帧 165 的厘米 float 148.5657501220703 投影为 1.4856574535369873 m/s。请求、响应、源身份及历史 240 样本引用见本目录。目标物理向量本身仍是 F32，不能据此恢复更早已经丢失的世界速度精度。

动画实际速度快照、gait 直接消费厘米 float 和 CMC 转向分别留给 D256a2、D256b、D256c。已写两个原生值、零值及实际速度快照系统反例；focused 测试、移除厘米 float 的消融、源码字节恢复后同启动器 target 重编、图静态审计和公共视觉 Gate 均待全部静态修复及 Bevy/依赖迁移后执行，目前尚未运行。
