# D100b4b2a4 胶囊三角面最终边接触

本地源启用 `UseCapsuleTriMesh2`。源只对至少一端满足边平面阈值且最近向量朝有效面侧的边追加点。最近点重合时，用轴与边方向的叉积并朝向三角面，拒绝朝边内的法线。仅当两个最近参数严格位于 `(0,1)` 且轴与面夹角满足源门槛时，沿面法线投影胶囊支持点并记录 `VertexPlane`。其余 `EdgeEdge` 点要求法线朝边外，若夹到顶点还须同时朝两条相邻边外侧。输出保持 a2 端帽、a3 平行边或圆柱和最后三条边的源顺序，跨面归并在后续阶段消费。

复用 a2 与 a3 保存的 9 组 15 个逐面原生结果，核对点数、顺序、类型、两个支持点、法线及深度。Stairs01 面 271 是边接触，Cart 988/989 的正面各有一个穿越转面点。新增零距离叉积翻面和钝角顶点法线范围 focused 用例，供统一 Gate 消融。原始读数的身份见 `input-identities.json`，当前未执行 Rust 测试、消融及 Playground。
