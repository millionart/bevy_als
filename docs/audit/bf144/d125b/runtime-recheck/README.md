# D125b 初始深穿透复验

正式角色查询的 100 m 宽、1 m 厚箱体中，胶囊起点在地面上表面下 20 cm。原生首缩短胶囊的穿透为 104 cm，重试胶囊为 56 cm，法线均向上。支持位置的原生对照返回正时扫掠 8.1499996 cm。

项目专用核已将该输入识别为 `DeepOverlap`。Parry 扫掠回退却可给出正时间，两个邻近 f32 胶囊尺寸分别得到穿透状态与 Converged。仅按状态置零的尝试在邻接尺寸及地板重试用例失败。初始姿态的 Parry 静态接触取得与原生相符的深度和法线，交给既有零时穿透映射和向外排除。

原生请求、完整压缩报告、初始失败和两种查询对照均在本目录。原生报告解压后可按 `source-identity.json` 重验 SHA-256。
