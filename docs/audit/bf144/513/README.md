# BF144.513 D05 对实际 Sprint 的影响

源 MS_Als_Normal 在 Standing / VelocityDirection 下绑定 Normal 动力曲线，旋转插值独立使用 Responsive。六条原生轴读数确认起步加速度、制动与摩擦分别为 20/15/5 和 25/20/10。可见对照只给一个角色复制运动参数，将 Responsive 的三条曲线或仅加速度轴换成 Normal，其他参数和原资产保持原值。

两个对照都把实际 Sprint 入场和 0.5 秒截止推迟一帧，与 UE 的序号相符。两者第 25 序号使用相同加速动画时点，完整 Normal 对照相对基线的 Root 姿态有 75 个骨骼记录改变。松开输入后，只有三曲线对照改变纵向减速轨迹。独立恢复复现入场与截止，完整参数从第 34 序号开始有物理末位差。

Normal 对照的第 26 序号保留 D07 的加速度阶段差。固定当前目标前态和步长，只把加速度标量换为源记录的旧缓存值，纵向计划速度由 4.56578 到 4.66672 m/s。UE 的对应速度为 4.66667 m/s。该对照是计划速度复算，实际物理阶段留待独立控制。

原导出器用新的原生样点反算得到现有 Normal 加速和 Responsive 制动两处切线。只换原生键的固定采样对照分别在 8 和 3 个实跑位置改变动力采样值，归入既有 D267。重放使用生产采样函数，恢复后报告逐字节一致。
