# BF144-D255b 地面输入加速乘积精度

fresh UE `CalcVelocity` 将 double `FVector` 加速度乘以 float 步长，随后以 double 累加和限速；目标此前先把乘积舍入为 F32。本项延迟该乘积的舍入，累计及限幅后仍按既有接口投回 F32。制动循环已在 D255a 单独处理。
