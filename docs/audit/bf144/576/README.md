# BF144.576 落地末步侧向速度分解

复用 575 封存的正负输入和原生报告。目标从实际 q58 初态重放公开运动核与场景扫掠，前两步无命中，第三步命中平地。剩余一个 Walking 子步的世界 X/Z 位置和发布速度与实际事务逐值相同。

| 对发布速度的贡献，µm/s | 正侧向 | 负侧向 |
|---|---:|---:|
| Walking 刷新加速度 7.5，源保留 20 | +50.89 | −51.03 |
| F32 世界位置差分 | −20.53 | −23.95 |
| 余时差，按共同缓存加速度 | +0.05 | +0.23 |
| 合计与原生的侧向速度差 | +30.42 | −74.76 |
