# BF144.492 已构造目标 Rig 的足骨选择

夹具调用生产 ControlRigBoundaryNode 与 evaluate_players，保持 BF144.459 实测的八帧姿态、曲线、绑定、时钟和两块地板。默认组逐值比较全部 VM 寄存器、局部骨骼、原调用和射线。另两组仅替换足选择布尔量，使用 BF144.491 的真实切换序列比较当前输入和已构造足根。显式重建组替换 player 组件以创建新图上下文，验证新实例重新读取当前值。源与目标均保持已构造足根，目标根单元读该足根，左右 TwoBoneIK 读取解剖腿骨。
