# BF144.519 单子步受阻走离的空中余时

复用宽 100 cm 半宽静态台，在同一 60 ms 前史后，以普通 30 Hz 的第 49 序号走离。源和目标都加入相同 45° 静态墙。三个墙距的原生帧前状态与无墙相同，受阻后同帧进入 Falling。按原生实际竖直速度回算，空中积分时间分别约 9.693、8.914 和 7.347 ms。无墙对照当帧余时为零。

162 cm 墙的目标水平请求为 0.194159 m，实际水平位移为 0.141462 m，按源比例规则可补回约 9.047 ms。目标实际在物理后发布 Air。只移除 D288 的旧弹簧后，水平结果和 Air 切换逐值相同，当帧竖直仍为零，下一帧才积分重力。UE 同墙在第 49 序号已经达到约 −0.095086 m/s。将这项独立时钟差登记为 D289。

撤掉弹簧控制后目标报告逐字节一致。五次原可见 Playground 功能通过，截图为零。
