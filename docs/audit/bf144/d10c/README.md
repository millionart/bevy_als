# BF144-D10c 跨步首次滑动的几何面资格

fresh UE `StepUp` 将前向命中的接触 `Normal` 与完整命中传给 `SlideAlongSurface`；后者在接触法线向上时，按命中的 `ImpactNormal` 判断不可行走，再将接触法线投影到水平面。高、低顶板原生控制的前向命中均选边缘竖直侧面，向下扫掠同一边缘均选水平顶面；高顶板组接触法线自身的竖直分量约 0.774，足以暴露旧目标误判。原生上组证据在 `docs/audit/bf144/d10a/`，本目录保存新读取的下组、两组 witness、源片段和 reader 身份。

目标 StepUp 首次前向扫掠使用共享几何面资格，同时仍用接触法线执行滑动；负竖直接触和近地板规则不变。新增正接触法线两种面资格对照，以及源高/低顶板场景的实际运动事务 fixture。测试、消融、图审计和真实 Playground Gate 待全部静态修复及 Bevy/依赖升级后执行。
