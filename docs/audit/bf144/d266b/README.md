# BF144-D266b 世界移动输入的夹限精度

本轮 fresh 原生重读 ±60° 对角输入、45°前向和两个目标 F32 可表示视角；请求、输出、watchdog、资产身份及 UE Pawn 输入累积/CMC 夹限源码均在本目录。−60° 的原生 double 世界输入经 CMC 夹限后投 F32 为 `(0.9659258127212524, 0, -0.2588191032409668)`；先投 F32 的旧路径会丢失末位。

当前目标每帧由一个二维命令生成水平移动输入，因此在投给 Tnua 的 F32 字段前完成 F64 二维 clamp、源方向组合和 CMC 最大长度 clamp；小于1的输入仍原样保幅。多个独立源输入累积和非水平重力约束不在本次证明范围。`projected-samples.json` 记录既有317个原生结果投 F32 后的长度平方，均不触发后续目标 F32 clamp；不外推未采样输入。D255 后续乘积和 D265 归一化精度仍独立。

已写两个目标可表示视角的原生精确结果及实际角色输入控制。全部静态修复及 Bevy/依赖迁移后执行 focused 测试、消融及原 Playground Gate；消融时在 CMC clamp 前提前投 F32，反例应失败，恢复源码字节并同 target 重编后复验。以上测试与消融尚未运行。
