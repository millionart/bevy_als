# BF144.579 实际胶囊扫掠的 GJK 终止条件

从本地锁定 Parry 0.27.0 提取 ray cast 函数到诊断程序。诊断程序复用同一目标构建中的 Parry 公共形体、support map 和 simplex。用 577、578 封存的八组实时输入，逐值复现同一库的公共 TOI、法线以及 Playground 原始 TOI。制动短胶囊半径使用运行时的 30 cm × 0.01 F32 乘积。

八组都在投影距离仍超过容差、已有正 TOI、上界不再缩小时返回。负侧落地及两个制动扫掠的最后支撑点被共面判定拒绝。另一个方向对照也被拒绝。余四组接收后投影又约化到三角形，上界仍没有缩小。

只在诊断副本跳过这个成功返回，七组改由距离容差退出，一组由完整 simplex 退出。负侧落地与 Chaos 的差从提前约 500 µm 变成推迟约 9 µm。原先相差约 17 nm 的正侧则变为推迟约 2.1 µm。原条件的重放与两次追加观测逐值一致。消融用于归因，生产库和阈值保持。
