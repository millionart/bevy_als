# D246a 网格挂载原点

原生 `AAlsCharacter` 将Mesh挂载设置为−92 cm，`USceneComponent` 在父空间以double合成。真实冷段中，角色Y=91.99999570846558 cm，原生Mesh原点为−4.291534423828125e−6 cm。目标以F32合成后再升精度，得到−5.9604644775390625e−6 cm。平面命中的两侧Trace偏移直接消费原点差。

源挂载常量保留厘米值，正式发布者在默认直接挂载时于厘米double合成Rig世界平移。原发布者稳定复现上述差值，同target恢复12项，涵盖自定义挂载和盒体、网格、复合形体等射线。真实319帧的冷段首六个有效Rig帧，两脚偏移及骨盆偏移全部与原生精确，首差的独立FootTarget输入保持原值。

公开Control Rig功能及渲染通过，临时观察入口在正式运行前已按源码字节移除。源、输入对照及原始报告见本目录和 `docs/audit/bf144/u07/source-root-history/`。
