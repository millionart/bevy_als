
# BF144-D246a 盒体射线世界精度

UE FootOffsetTrace 的世界射线和 ImpactPoint 使用 double 厘米；目标原先将世界起点、方向和命中点都降到 F32。fresh 原生请求复采 `.462/.463` 的左脚盒体 ray，世界起终点、hit 和局部结果与封存源记录逐值相同。对应源盒体在 runtime 为中心 `(-10,-0.25,-20)` m、半尺寸 `(20,0.25,10)` m。完整请求、结果、源码和哈希在本目录，压缩输出已逐字节核对解压。

`RigQueryContext` 对 scaled cuboid 在局部保留 F64 射线参数，使用当前依赖树已有的 Parry 0.27 双精度 Cuboid，并按原始 F64 世界 segment 重建命中；结果继续参与原过滤和最近命中选择。新增源水平面坐标、起点在盒内、盒体与原 F32 球体混合最近命中及过滤 fixture。项目直接声明已存在于锁文件的 `parry3d-f64`；其解析和编译尚待统一验证。

三角网格和其他形状暂保留原 F32 路径，继续由 D246b 处理；碰撞体本身的位置、旋转及顶点仍来自 F32，Parry 与 UE Chaos 的所有边界也未声称相同。测试、消融与恢复、完整图审计和公共 Playground Gate 均待全部静态修复及 Bevy/依赖迁移后执行。
