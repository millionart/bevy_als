# BF144.516 同帧 Walking→Falling 加速度交接

源与目标都按失去支撑的实际水平步距补回余时。隔离 UE 读取器支持静态平台宽度，第一轮误用旧包的结果单独保存。可见 Playground 保留原地形，加入静态测试平台。70 cm 半宽的较晚见证固定为第 48 序号的 60 ms 帧。两端都先完成约 30 ms Walking，再执行约 30 ms Falling。

UE 的帧内缓存为 11.363149 m/s²，空中增速约 0.051134 m/s。Bevy 在同类见证的帧内旧值为 12.007459 m/s²，却以通用 20 m/s² 生成空中输入。单独把事务期间的通用上限换为旧缓存，Walking 末速和下落速度逐值一致，末速由 5.350549 变为 5.314583 m/s，InAir Lean 也变化。事务后恢复设置，第 49 序号两组的空中增速一致。D287 与既有 D07 的步行积分差分开验证。

早期半宽 35 cm 的第 46 序号控制只恢复 Walking 缓存，复现 D07 向空中末速传播。目标宽台对照保持 Grounded。去控制后较晚见证逐值恢复。八次可见功能通过，截图为零。
