# BF144.577 台外落地余时的几何分解

复用 576 的正负实际落地。Playground 碰撞体是中心 [0, −0.25, −20] m、半尺寸 [10, 0.25, 10] m 的盒。源资产 BodySetup 重读也给出 20×20×0.5 m 的简单盒。两端按共同世界起点、胶囊尺寸、方向和长度执行原始查询。

正负两组 Chaos 原始距离都是 0.1624860001 m。Bevy 正侧为 0.1624860168 m，负侧为 0.1619857550 m。单碰撞体直接调用和场景查询逐值一致，把盒体移到相对原点后结果也相同。负侧命中时两个见证点的竖直分离约 0.327 mm。控制只反转侧向分量时，Chaos 保持距离，Bevy 在实际输入范围内出现不同距离。

| 对 Walking 余时的贡献 | 正侧 | 负侧 |
|---|---:|---:|
| 起始高度 | −10.839 µs | −10.839 µs |
| 共同输入的原始命中差 | −0.002 µs | +58.943 µs |
| 同一原始距离的拉回差 | 0 | 0 |

把起点换为原生高度后，共同输入核与原生实际余时相差约 9 ns。负侧原始查询差补入 D125。前态约 59 µm 的高度差已量化，其更早写入阶段仍待核对。原始查询为何在此停止的内部分支尚未插桩。

两组公共功能报告继续保留 572 已归因的骨盆告警，原判据保持。截图 0，性能验收暂停。
