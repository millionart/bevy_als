# BF144-D95 速度阶段不再预测位置间距

fresh PA的head形体和材质与D65a受跟踪源记录逐字节相同。源位置阶段使用固定力臂的线性修正；进入法向速度阶段后只使用速度与目标回弹，不再以当前位置残差附加预测偏置。Avian在Relax时仍会重新计算旋转后的间距，并对正间距加入`separation / dt`。

目标在Relax前仅处理最初已重叠的Ragdoll接触：当本帧修正使目标间距转正时，临时调整该点的目标输入使速度阶段看到零间距；Relax后逐点恢复原值，保留后续子步与接触几何。已写正间距、仍重叠、原本预测接触、非Ragdoll和恢复控制，并给加载head的位置摩擦对照增加法向速度断言。

目标尚未出现的预测接触仍由D98处理，零位置冲量点的速度资格归D139。测试、消融及Playground待统一Gate。
