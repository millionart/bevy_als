# BF144.518 单子步走离的竖直 motor

宽 100 cm 半宽台的第 49 序号中，UE 执行完整水平步后切 Falling，竖直速度为零。相同可见目标场景的目的地缺少 floor，单子步事务保留前支撑产生的竖直 motor。旧支撑平台速度为零。

Tnua 弹簧为 9.118581 m/s²。保留重力补偿，考虑项目的物理上限与角色时钟换算，Avian 六子步逐值复现原始速度 0.3039527 m/s 和抬升。物理后状态同步才发布 Air，并带入这股竖直速度。只移除弹簧项，水平结果和 Air 切换相同，竖直速度归零，下一帧按重力积分。更宽台仍有目的地支撑，原事务会取消该弹簧。去掉控制后参数报告逐字节一致。

本项记录离地交接保留旧力的 D288。D31 记录有效支撑期间的带内悬浮。四次原可见 Playground 功能通过，截图为零。
